# AreaChart Examples

Run the gallery from the repository root:

```bash
go run ./examples/area-chart/cmd
```

Regenerate only this capture from `examples/`:

```bash
make area-chart
```

The project demonstrates smooth overlapping areas, regular stacks, normalized
step areas, optional values, `GapBreak`, custom fills, and custom strokes.
