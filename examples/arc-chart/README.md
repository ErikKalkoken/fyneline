# ArcChart Examples

Run the gallery from the repository root:

```bash
go run ./examples/arc-chart/cmd
```

Regenerate only this capture from `examples/`:

```bash
make arc-chart
```

The project demonstrates labeled pies, doughnuts, partial gauges, radial
segments, inner and outer radii, angle ranges, padding, and rounded corners.
