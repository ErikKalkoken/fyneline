# Spline Examples

Run the gallery from the repository root:

```bash
go run ./examples/spline/cmd
```

Regenerate only this capture from `examples/`:

```bash
make spline
```

The project demonstrates linear, monotone-x, and step-after curves, multiple
series, optional values, `GapBreak`, grid visibility, colors, and stroke widths.
