# BarChart Examples

Run the gallery from the repository root:

```bash
go run ./examples/bar-chart/cmd
```

Regenerate only this capture from `examples/`:

```bash
make bar-chart
```

The project demonstrates grouped series, regular stacks, horizontal diverging
stacks, normalized stacks, custom colors, grid options, padding, fixed domains,
and percentage formatting.
